# Agent frontend

TanStack Start with React, TanStack Query, Vite, Tailwind CSS and locally owned shadcn/ui components. Dependencies are pinned to the npm `latest` tags resolved on November 7, 2026; Node type definitions follow the Node 24 runtime.

From the `agent` workspace root:

```sh
npm run dev --workspace @agent/agent-frontend
npm run build --workspace @agent/agent-frontend
npm run typecheck --workspace @agent/agent-frontend
npm run start --workspace @agent/agent-frontend
```

The development server listens on port 3000. Production uses Nitro's Node server at `.output/server/index.mjs`; `HOST` and `PORT` configure its bind address. Nitro's current latest release is a release candidate, as used by the current TanStack Start hosting guide. The route tree is generated by Vite; run the build once before a fresh-checkout typecheck.

The initial screen intentionally has no fabricated nodes or chat responses. Suggested prompts fill the composer; sending stays disabled until the backend chat integration is implemented. The routing control exposes automatic mode and explains why explicit node selection is unavailable. TanStack Query has an isolated cache for each router instance, ready for the future node registry and chat APIs.

Add components using `npm run ui:add --workspace @agent/agent-frontend -- <component>`. `components.json` configures the Tailwind v4 stylesheet and source aliases.

Setup references: [TanStack Start](https://tanstack.com/start/latest/docs/framework/react/build-from-scratch), [Node deployment](https://tanstack.com/start/latest/docs/framework/react/guide/hosting), [shadcn installation](https://ui.shadcn.com/docs/installation/tanstack-router).
